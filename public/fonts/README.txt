# Invitation typefaces

The screenshot does not identify its original fonts. These are visual matches, not verified identifications.

- `cairo-light.ttf`: Cairo Light, weight 300, retrieved from the Google Fonts CSS API. See `Cairo-OFL.txt`.
- `traditional-arabic.ttf`: Traditional Arabic Regular, from the local Windows font collection.
- `traditional-arabic-bold.ttf`: Traditional Arabic Bold, from the local Windows font collection.

The dedication uses Cairo Light for the geometric copy, Traditional Arabic Bold for the title and Traditional Arabic Regular for the prayer. Fonts are bundled locally so the layout does not depend on fonts installed on the viewing device. Arabic tatweel characters reproduce the extended connections in the reference.

Cairo source: https://fonts.googleapis.com/css2?family=Cairo:wght@300&display=swap
Cairo project/license: https://github.com/google/fonts/tree/main/ofl/cairo

Final scene English name: edwardian-script.ttf is Edwardian Script ITC from the local Windows font collection.
